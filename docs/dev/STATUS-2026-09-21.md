## 已完成

### M0 正确性（后端已落地，部分已测）

- SSE 跨协议流式翻译（`internal/gateway/stream.go`）
- 路由填 `ToolCallRequired / VisionRequired / ReasoningRequired`（`caps.go`）
- 401 → `DisableKey` 标记该 Channel Key
- `RequestRecord`：`ttft_ms, finish_reason, upstream_model, cache_read/write_tokens`；迁移 **008** 已写入 `migrations` 切片
- Sticky 5 分钟（`internal/affinity`）
- `HTTPUpstream` 使用 `Channel.ProxyURL`
- 429 且 `Retry-After ≤ 2s` 本地等待再试
- ROADMAP 路由策略与 selector 对齐

### M1 钱与号（代码在，全量测试未在 1.27 验证）

- Identity Bundle：`internal/identity`；`GET/PATCH /api/v1/identity`
- 粘性 session + 优先 `PreferredKeyID`（取消盲目全局 RR 当有 sticky key）
- 同协议透传 `cache_control`；跨协议转换尽量保留
- AIMD：`internal/ratelimit`；网关 `Wait`（≤2s 排队，更长换渠道）+ `Observe`
- Check-in adapter 经 `identity.HTTPClient` 走渠道代理
- UI Pulse：缓存命中；渠道 Inspector 代理/身份/信任占位已接 API

### M2 信任与可观测
